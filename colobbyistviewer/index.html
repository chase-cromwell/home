How it works

Install once. Works on every bill.

1

Install the extension

Add it to Chrome in one click from the Chrome Web Store. No account, no sign-in, no setup required.

2

Navigate to any bill

Go to leg.colorado.gov and open any bill or resolution page. The extension activates automatically.

3

Click the Lobbyists tab

A new tab appears alongside the existing ones. Click it to see who's filed positions, search by name, and sort by stance.

About the data

Public record, made accessible.

All lobbyist disclosure data is public record, required by Colorado law and filed with the Secretary of State. This extension just makes it easier to find.

Source

Data comes from the Colorado Secretary of State's Professional Lobbyist Bills dataset, published via the Colorado Information Marketplace.

Update frequency

Lobbyist positions are reported monthly during session (January–May). The extension's database refreshes nightly. Data may lag current activity by up to 30 days during session.

Data processing

Raw state data is cleaned for readability — capitalization normalized, redundant firm names removed. Multiple monthly filings are consolidated into unified timelines, and lobbyists for the same client with the same stance are grouped into one entry.

Limitations

Registrations are self-reported. The same organization sometimes appears under slightly different name spellings, which can create duplicate entries. Use position counts as a general indicator, not a precise tally.

Permissions & Privacy

Minimal access. Nothing unexpected.

CO Lobbyist Viewer requests three permissions — here's exactly what each one does.

leg.colorado.gov access

The extension only activates on Colorado General Assembly bill pages. It cannot read or modify any other website you visit.

Storage

Saves a single randomly generated anonymous ID to your browser so returning visits aren't counted as new users in aggregate analytics. No personal information is stored.

Active tab

Allows the extension to add the Lobbyists tab to the page you're currently viewing. It does not run in the background or access tabs you haven't opened. The extension never reads your browsing history, accesses other tabs, or transmits any personally identifiable information.

What data is collected

  • Bill pages visited — the bill number is logged when you visit a bill page with the extension active.
  • Feature usage — whether you opened the Lobbyists tab, used search, or sorted results. No search queries are recorded.
  • An anonymous identifier — a randomly generated ID stored locally in your browser. Cannot be linked to you personally.

What is NOT collected

  • Your name, email, or any personally identifiable information
  • Your IP address
  • The content of any search query
  • Any information from other websites or tabs

Data processors

  • Google Analytics (GA4) via the Measurement Protocol API. Data is sent from a server, not directly from your browser. Subject to Google's Privacy Policy. No cookies are set.
  • Cloudflare — the extension's data API runs on Cloudflare Workers. Subject to Cloudflare's Privacy Policy.

Why is this data collected?

  • Understanding the features you use and legislation pages you visit (only within leg.colorado.gov) helps identify bugs
  • Identifying where and how this tool is used (especially malfunctions) prevents abuse - and prevents unintended abuse of the Colorado Legislature's website

Lobbyist data

All lobbyist disclosure data is public record provided by the Colorado Secretary of State. No private information is displayed.
